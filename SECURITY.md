# Security

This early release is a static, device-local planner. Do not treat browser storage as confidential storage or use the app for sensitive evidence, regulated records, or financial transactions.

Report suspected vulnerabilities through GitHub's private vulnerability reporting feature if enabled. If it is unavailable, open an issue asking for a private contact without revealing the vulnerability or sensitive information. Do not post exploit details, secrets, personal information, or precise private locations in public issues.

Only the current main branch is maintained. There is no guaranteed response time or security service-level agreement.
